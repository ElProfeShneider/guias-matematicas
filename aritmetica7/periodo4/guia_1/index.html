EXPLORACIÓN

Un mismo procedimiento con números diferentes

Observa las siguientes expresiones:

2 × 3 + 5

2 × 7 + 5

2 × 12 + 5

Las tres expresiones siguen la misma estructura.

  1. ¿Qué valor cambia en las tres expresiones y qué operaciones permanecen iguales? Coméntalo con un compañero.

ANALIZA

Ahora utilizaremos la letra n para ocupar el lugar de un número. Observa con atención qué indica cada expresión.

1. El orden cambia el significado

Observa:

A. n − 5

B. 5 − n

Lee las frases:

  • A un número se le restan 5.
  • A 5 se le resta un número.
  1. ★ ✎ RELACIONA: Escribe qué frase corresponde a cada expresión.
  2. Reemplaza n por 8 y calcula las dos expresiones. ¿Obtienes el mismo resultado? Explica oralmente qué muestra esta comparación.

2. Una misma operación puede organizarse de forma diferente

Observa:

A. 2 × n + 3

B. 2 × (n + 3)

Frase 1: Al doble de un número se le suman 3.

Frase 2: A un número se le suman 3 y después se duplica el resultado.

  1. ★ ✎ RELACIONA: Escribe qué expresión corresponde a cada frase.
  2. ✎ COMPRUEBA: Reemplaza n por 4 en las dos expresiones y calcula. ¿Los resultados son iguales o diferentes? Explica en una frase qué debes observar al pasar de una expresión escrita con palabras a una expresión matemática.

CONOCE ALGO NUEVO

En ANALIZA comprobaste que una letra puede ocupar el lugar de un número y que el orden de las operaciones cambia el significado de una expresión. Ahora vas a organizar estas ideas mediante el lenguaje algebraico.

1. ¿Qué es una expresión algebraica?

El lenguaje natural comunica ideas matemáticas mediante palabras. El lenguaje algebraico representa esas ideas mediante números, letras y signos de operación.

★ ✎ COPIA – Idea esencial

Una expresión algebraica combina números, letras y operaciones para representar cantidades o relaciones de manera general.

Observa la expresión:

3n + 7

n es la variable: representa un número que puede cambiar o cuyo valor aún no se conoce.

3 es el coeficiente: es el número que multiplica a la variable.

7 es el término constante: no contiene variable y su valor permanece fijo.

Cuando un número multiplica una letra, normalmente se omite el signo ×:

3 × n = 3n      5 × a = 5a

2. Algunas expresiones frecuentes

Observa cómo una misma idea puede escribirse con palabras y mediante símbolos.

Lenguaje natural Lenguaje algebraico
Un número aumentado en 5 n + 5
A un número se le restan 5 n − 5
A 5 se le resta un número 5 − n
El doble de un número 2n
El triple de un número 3n
La mitad de un número n 2

Estas correspondencias ayudan a interpretar una frase, pero también debes respetar el orden de las operaciones.

3. Del lenguaje natural al lenguaje algebraico

★ ✎ COPIA – Procedimiento base

  1. Representa con una letra el número que puede cambiar o que no se conoce.
  2. Identifica las operaciones indicadas en la frase.
  3. Escribe la expresión respetando el orden y la agrupación de las operaciones.

★ ✎ COPIA – Ejemplo esencial

Representa algebraicamente:

Al triple de un número se le suman 4.

Representamos el número con n.

Su triple es 3n y después se suman 4.

3n + 4

Verificación breve: representa oralmente “al doble de un número se le restan 6”.

4. Del lenguaje algebraico al lenguaje natural

★ ✎ COPIA – Procedimiento base

  1. Identifica la variable.
  2. Observa las operaciones y el orden en que aparecen.
  3. Expresa con palabras la relación completa.

★ ✎ COPIA – Ejemplo esencial

5n − 2

Esta expresión puede leerse: “Al quíntuple de un número se le restan 2”.

El orden y los paréntesis también cambian el significado:

2n + 3 → Al doble de un número se le suman 3.

2(n + 3) → El doble de la suma de un número y 3.

Verificación breve: explica oralmente qué representa la expresión n + 8.

★ ✎ COPIA – Síntesis esencial: El lenguaje algebraico permite representar cantidades y relaciones mediante números, letras y operaciones. Para traducir correctamente una expresión, es necesario reconocer la variable y respetar el orden y la agrupación de las operaciones.
