Operaciones con fracciones algebraicas

Multiplicación, división, suma y resta de fracciones algebraicas

EXPLORACIÓN

1. Recuerdo cómo opero fracciones

Observa las siguientes operaciones:

2 5  +  1 5       2 5  ×  3 4

Comenta oralmente: ¿los denominadores se utilizan de la misma manera al sumar y al multiplicar fracciones?

✎ RESUELVE: calcula las dos operaciones y escribe sus resultados en el cuaderno.

2. Observo qué cambia al aparecer expresiones algebraicas

Compara las siguientes operaciones:

A.  x x + 2  +  3 x + 2    con x ≠ −2
B.  x x + 2  ×  x + 2 5    con x ≠ −2

★ ✎ RESPONDE:

  1. En A, ¿qué tienen en común los dos denominadores?
  2. En B, ¿qué factor aparece completo en un numerador y en un denominador? ¿Qué valor de x continúa excluido?

ANALIZA

1. Comparo dos propuestas

Dos estudiantes intentan resolver la siguiente suma:

x x + 2  +  3 x + 2    con x ≠ −2

Propuesta 1

x + 3 x + 2

Propuesta 2

x + 3 2x + 4

★ ✎ ANALIZA:

  1. Sustituye x = 3 en la suma original y en las dos propuestas. Escribe los tres resultados.
  2. ¿Cuál propuesta puedes descartar con seguridad? Después responde: ¿que la otra propuesta coincida para x = 3 demuestra que es correcta para todos los valores permitidos? Escribe una razón breve.

2. Distingo cuándo un factor puede simplificarse

Observa estas dos operaciones. En ambas se consideran x ≠ 2 y x ≠ −4.

I.  x + 1 x − 2  ×  x − 2 x + 4
II.  x + 1 x − 2  +  x − 2 x + 4

★ ✎ RESPONDE:

  1. ¿En cuál operación x − 2 aparece como factor completo en un numerador y en un denominador dentro de una multiplicación?
  2. En II, ¿sería correcto eliminar x − 2 solamente porque aparece una vez arriba y otra abajo? Responde sí o no y escribe una razón breve.

CONOCE ALGO NUEVO

1. Antes de operar

En la guía anterior aprendiste a simplificar fracciones algebraicas y a identificar sus valores excluidos. Estas ideas siguen siendo necesarias al realizar operaciones.

★ ✎ COPIA – Idea esencial: antes de operar, determina las restricciones de la operación original. Ningún denominador puede ser cero y, si hay una división, la fracción que funciona como divisor tampoco puede ser igual a cero.

Las restricciones se conservan aunque durante el procedimiento algunos factores se simplifiquen.

Cuidado: solo pueden simplificarse factores completos que estén multiplicando en el numerador y en el denominador. No se cancelan términos separados por una suma o una resta.

2. Multiplicación de fracciones algebraicas

Para multiplicar fracciones algebraicas, multiplica los numeradores entre sí y los denominadores entre sí. Si es posible, factoriza y simplifica factores comunes.

★ ✎ COPIA – Regla fundamental:

A B × C D = A · C B · D , con B ≠ 0 y D ≠ 0

Ejemplo

x x + 2 × x + 2 5 = x 5

Restricción: x ≠ −2.

El factor x + 2 puede simplificarse porque aparece completo en un numerador y en un denominador dentro de una multiplicación. La restricción x ≠ −2 se conserva.

3. División de fracciones algebraicas

Para dividir fracciones algebraicas, conserva la primera fracción y multiplícala por el recíproco de la segunda; es decir, intercambia el numerador y el denominador de la fracción divisora.

★ ✎ COPIA – Procedimiento base:

A B ÷ C D = A B × D C

B ≠ 0, D ≠ 0 y C ≠ 0.

La condición C ≠ 0 aparece porque la segunda fracción es el divisor y no se puede dividir entre cero.

Ejemplo

2 x − 1 ÷ x x + 3 = 2 x − 1 × x + 3 x = 2(x + 3) x(x − 1)

Restricciones: x ≠ 1, x ≠ −3 y x ≠ 0.

4. Suma y resta con igual denominador

Si las fracciones tienen el mismo denominador, suma o resta los numeradores y conserva el denominador.

★ ✎ COPIA – Regla fundamental:

A B ± C B = A ± C B , con B ≠ 0

Ejemplo

x x + 2 + 3 x + 2 = x + 3 x + 2

Restricción: x ≠ −2.

Cuidado: cuando los denominadores son iguales, no se suman ni se restan entre sí.

5. Suma y resta con diferente denominador

Si los denominadores son diferentes, primero debes encontrar un denominador común. Cuando los denominadores puedan factorizarse, hacerlo puede ayudarte a encontrar uno más sencillo.

★ ✎ COPIA – Procedimiento base:

  1. Determina las restricciones de las fracciones originales.
  2. Factoriza los denominadores cuando sea necesario.
  3. Encuentra un denominador común.
  4. Escribe fracciones equivalentes con ese denominador.
  5. Suma o resta los numeradores.
  6. Simplifica el resultado si es posible y conserva las restricciones originales.

Si no existe un denominador común más sencillo, el producto de los denominadores puede utilizarse:

A B ± C D = AD ± BC BD , con B ≠ 0 y D ≠ 0

Ejemplo

2 x − 1 x + 1

Restricciones: x ≠ 0 y x ≠ −1.

= 2(x + 1) − x x(x + 1) = x + 2 x(x + 1)

6. Verificación breve

★ ✎ RESUELVE:

  1. Simplifica el producto e indica la restricción:
    x − 3 x + 1 × x + 1 2
  2. Suma y conserva las restricciones:
    1 x + 1 x + 2
