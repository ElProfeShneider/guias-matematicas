Fracciones algebraicas

Cocientes entre expresiones algebraicas y simplificación mediante factorización

Observa:

Sustituye solamente en el denominador:

x = 3    →    x − 3 = ______

ANALIZA

1. Distingo un factor de un término

Compara:

I.  (x + 2)(x + 5) x + 2
II.  (x + 2) + 5 x + 2

Observa que en I, x + 2 multiplica a otro factor. En II, x + 2 forma parte de una suma.

★ ✎ ANALIZA: ¿en cuál expresión x + 2 es factor de todo el numerador y también aparece como factor en el denominador?

Comenta oralmente: ¿por qué no sería correcto eliminar x + 2 solamente porque aparece arriba y abajo?

2. La factorización permite reconocer factores

Observa la expresión:

x2 − 9 x − 3

Recuerda:

x2 − 9 = (x − 3)(x + 3)

Entonces:

(x − 3)(x + 3) x − 3

★ ✎ COMPLETA Y RESPONDE:

1. Después de reconocer el factor común x − 3, la expresión puede simplificarse a ____________________.

2. ¿Puede utilizarse x = 3 en la expresión original? Escribe una razón breve.

CONOCE ALGO NUEVO

1. ¿Qué es una fracción algebraica?

★ ✎ COPIA – Idea esencial: Una fracción algebraica es un cociente indicado entre expresiones algebraicas. Se representa de la forma:

A B    con    B ≠ 0

A y B representan expresiones algebraicas. La expresión de arriba es el numerador y la de abajo es el denominador.

El numerador puede tomar el valor 0, pero el denominador nunca puede ser 0.

Ejemplo:

x + 4 x − 2

El valor x = 2 no está permitido porque convierte el denominador en 0.

2. ¿Cómo se simplifica?

Simplificar una fracción algebraica significa escribirla de una forma equivalente más sencilla, conservando los valores que estaban permitidos en la expresión original.

★ ✎ COPIA – Procedimiento base:

  1. Identifica los valores que hacen cero el denominador original y exclúyelos.
  2. Factoriza el numerador y el denominador cuando sea necesario.
  3. Identifica los factores comunes.
  4. Simplifica los factores comunes.
  5. Conserva las restricciones de la fracción original.

Solo se simplifican factores comunes. No se eliminan términos que formen parte de una suma o una resta.

3. Ejemplo esencial

Observa cómo se simplifica:

x2 − 9 x − 3

Primero se identifica la restricción:

x − 3 = 0   →   x = 3

Por tanto: x ≠ 3

Después se factoriza el numerador:

x2 − 9 = (x − 3)(x + 3)

(x − 3)(x + 3) x − 3  =  x + 3

★ ✎ COPIA – Ejemplo esencial:

x2 − 9 x − 3  =  x + 3,    x ≠ 3

Aunque la expresión simplificada sea x + 3, el valor x = 3 continúa excluido porque no estaba permitido en la fracción original.

4. Una idea que debes conservar

factorizar → reconocer factores comunes → simplificar

La factorización permite descubrir factores que no siempre son visibles en la expresión inicial.
